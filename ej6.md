# Ejercicio 6: TelefonoInteligente

## Explicación Lógica
1. **Implementación Múltiple:** Java supera la restricción de herencia simple permitiendo que una clase implemente múltiples interfaces (`Conectable` y `Recargable`).
2. **Visibilidad por Referencia:** El tipo de variable utilizada (`Conectable` o `Recargable`) restringe los métodos visibles únicamente a los estipulados por dicho contrato.
